Understand how Lumina surgically dissects presentation layout trees, preserves high-fidelity vector primitives, and exposes clean REST endpoints.

PDF

1. PDF Bounding-Box Detection Engine

processors/pdf/detector.py & remover.py

Gamma generates PDF documents with clickable watermark badges near the bottom-right corner. Lumina utilizes PyMuPDF (fitz) to inspect link annotations, bounding box dimensions, and target URLs:

  • Spatial Filtering: Analyzes element bounding boxes situated in the bottom 30% height and right 30% width region.
  • URI Inspection: Inspects URI action dictionaries targeting gamma.app.
  • Surgical Removal: Prunes both the underlying image object stream and the link annotation layer, preserving text flow and background vectors.
PPTX

2. PowerPoint XML AST Pruning Engine

processors/pptx/detector.py & remover.py

PowerPoint presentations embed watermarks within slide master XML schemas and layout definitions:

  • Master Traversal: Recursively loops through slide_masters and their child slide_layouts.
  • Shape Relationship Targeting: Detects XML shape nodes containing a:hlinkClick with Gamma relationship targets.
  • Lossless Layout Cleanup: Deletes the specific shape tree element from the XML tree without re-encoding fonts, animations, or slide shapes.

REST API Endpoint

POST /api/remove-watermark
HTTP 200 / multipart/form-data

Integrate Lumina directly into your CI/CD pipelines, automated presentation generators, or batch scripts.

cURL Example 
curl -X POST http://localhost:8999/api/remove-watermark \
  -F "file=@presentation.pptx"
Python (requests) 
import requests

url = "http://localhost:8999/api/remove-watermark"
files = {"file": open("presentation.pptx", "rb")}

response = requests.post(url, files=files)
data = response.json()

print(f"Watermarks Removed: {data['watermarks_removed']}")
print(f"Clean Download URL: {data['download_url']}")
